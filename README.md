# Коммерческое предложение: караоке-комнаты IZUMI

Статическая страница. Сборки нет, внешние сервисы не вызываются.

Шрифт Montserrat лежит в `fonts/`. Это тот же набор, что на izumi.moscow: кириллица, латиница и знак ₽. Страница берёт файлы из папки проекта, не из сети.

## Запуск

Откройте `index.html` двойным щелчком или перетащите файл в браузер.

Печать и сохранение в PDF: `Cmd+P`, затем «Сохранить как PDF». Страница сама PDF не создаёт.

Проверка формул, если установлен Node:

```bash
node --test
```

## Где менять данные

- Название исполнителя и контакты: `js/data/proposal.js`, поля `executor` и `contacts`. Пока они пустые, на странице их нет.
- Дата предложения: `js/data/pricing.js`, поле `proposalDate`. Срок «15 календарных дней» в текстах условий: `js/data/proposal.js`.
- Цены, состав работ, модули, регулярные расходы: `js/data/pricing.js`. Формулы читают эти числа из `js/utils/calculations.js`.
- Учебное меню: `js/data/demoMenu.js`.
- Вопросы, этапы и остальные тексты: `js/data/faq.js`, `js/data/timeline.js`, `js/data/proposal.js`.

После правки цен запустите `node --test`. Контрольные суммы полного объекта и пилота изменились — тесты это покажут.
